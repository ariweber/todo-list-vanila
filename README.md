## יכולות

- הוספת משימה (בכפתור "הוסף" או במקש Enter)
- סימון משימה כבוצעה. משימות שבוצעו יורדות לסוף הרשימה

- מחיקת משימה בודדת
- מחיקת כל המשימות שבוצעו, או מחיקת הכל

## דרישות

- [Node.js](https://nodejs.org/) גרסה 16.20 ומעלה

## הרצה

```bash
npm install
npm start
```

`npm start` מקמפל את הקוד לתיקייה `dist/` ומפעיל שרת מקומי. אחר כך פותחים בדפדפן את הכתובת שמודפסת (בדרך כלל `http://localhost:3000`).

> אין לפתוח את `index.html` ישירות מהקובץ (`file://`). הדפדפן חוסם מודולים במצב הזה, והאפליקציה לא תעבוד.


## מבנה הפרויקט

```
  view.ts        רינדור הרשימה
  dom.ts         פונקציות עזר ליצירת אלמנטים

  types.ts       טיפוסים
```
